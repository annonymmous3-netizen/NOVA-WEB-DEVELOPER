How Monthly Licensing Works
Register the website once → collect the monthly payment → generate a single-use activation code → customer enters it in the website Subscription screen → the website becomes active until the end of the next calendar month. Five days before expiry, the customer website and this master dashboard show a renewal warning. After expiry, the website blocks normal use until a new code is activated.
